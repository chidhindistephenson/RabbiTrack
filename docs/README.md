# RabbiTrack Docs

This directory holds product and engineering documents for the RabbiTrack build.

## Contents

- `architecture.md` - current implementation architecture baseline.
- `api/openapi.yaml` - starter OpenAPI contract for versioned REST endpoints.
- `adr/0001-modular-monolith.md` - first architecture decision record.
- `offline-qa-checklist.md` - internal checklist for offline APK smoke testing.
- `offline-tester-guide.md` - Android APK tester instructions for offline farm feedback.
- `tester-feedback-form.md` - questions to send to farm testers after APK testing.

The approved SRS remains the source of truth for MVP scope until requirements are split into issues.
